# Task 2: Advanced Exploratory Data Analysis

## Overview
A sales analytics project using Python, Pandas, NumPy,
Matplotlib and Seaborn.

## Features
- Data cleaning and duplicate removal
- Sales KPIs and summary statistics
- Sales by category and city
- Sales distribution analysis
- Correlation heatmap
- Exported cleaned data and summary report

## How to Run
```bash
python -m pip install -r requirements.txt
python analysis.py
```

## Outputs
Generated files are saved in the `output` folder,
including cleaned data, CSV summaries, charts and a report.
